# 产品拆分方案：AnkiGenix vs AI学习教练

## 战略决策：拆分为两个独立产品

### 核心问题
**是否应该将"闪卡生成"和"AI学习教练"拆分为两个独立产品？**

**答案：是的，强烈建议拆分** ✅

---

## 产品拆分对比

| 维度 | 产品A：AnkiGenix | 产品B：AI学习教练（新产品） |
|------|-----------------|---------------------------|
| **核心定位** | 专业闪卡生成工具 | AI个性化学习平台 |
| **目标用户** | Anki重度用户、效率工具爱好者 | 想系统学习新技能的学习者 |
| **用户场景** | 已有学习材料，需要快速转换为闪卡 | 从零开始学习，需要完整学习路径 |
| **核心价值** | 快速、准确、多格式输入 | 个性化、系统化、AI陪伴 |
| **产品类型** | 工具型产品（Tool） | 平台型产品（Platform） |
| **使用频次** | 按需使用（有材料时） | 每日使用（持续学习） |
| **付费逻辑** | 按使用量付费 or 订阅 | 订阅制（月费/年费） |
| **竞品参照** | Quizlet, Brainscape | Duolingo, Coursera |
| **开发复杂度** | 低-中 | 高 |
| **市场规模** | 中等（Anki用户群体） | 大（所有在线学习用户） |

## 产品A：AnkiGenix - 专业闪卡生成工具

### 产品定位
**The Ultimate AI-Powered Flashcard Generator**
最专业的AI闪卡生成工具，帮助Anki用户快速、准确地将学习材料转换为高质量闪卡。

### 核心功能（保留并强化现有）

#### 1. 多源输入（Multi-Source Input）⭐ 核心卖点
```
支持的输入方式：
├── 📝 文本输入（Text）
│   └── 直接粘贴学习内容
├── 📄 文件上传（File Upload）
│   ├── PDF文档
│   ├── Word文档
│   ├── PowerPoint幻灯片
│   ├── Markdown文件
│   └── 图片（OCR识别）
├── 🌐 网页爬取（Web Crawler）
│   ├── 博客文章
│   ├── 维基百科
│   ├── 在线教程
│   └── YouTube字幕
├── 📚 电子书导入（E-book Import）
│   ├── EPUB
│   └── MOBI
└── 🎥 视频字幕（Video Subtitle）
    └── 上传字幕文件或YouTube链接
```

#### 2. 智能章节识别（Intelligent Section Recognition）
```
自动识别文档结构：
├── 识别标题层级（H1/H2/H3）
├── 提取章节大纲
├── 用户选择需要生成闪卡的章节
└── 批量生成（支持全部或选择性生成）
```

#### 3. 多种闪卡类型（Multiple Card Types）
```
├── Basic Card（基础卡片）
│   └── 问题 → 答案
├── Cloze Card（填空卡片）
│   └── 文本中挖空关键词
├── Multiple Choice（选择题）
│   └── 问题 + 4个选项
├── Image Occlusion（图片遮挡）
│   └── 遮挡图片部分内容
└── List Card（列表卡片）
    └── 列举要点
```

#### 4. 高精度生成（High Accuracy Generation）
```
质量保证：
├── AI模型选择（GPT-4 / Claude / Deepseek）
├── 可调节生成参数
│   ├── 卡片数量
│   ├── 难度级别
│   └── 详细程度
├── 自动去重（避免重复卡片）
├── 智能标签（自动添加标签）
└── 源文本引用（每张卡片显示来源）
```

#### 5. 灵活导出（Flexible Export）
```
导出格式：
├── .apkg（Anki标准格式）⭐
├── .csv（CSV格式）
├── .xlsx（Excel格式）
├── JSON（API对接）
└── Quizlet导入格式
```

#### 6. 批量处理（Batch Processing）
```
高效工作流：
├── 一次上传多个文件
├── 批量生成闪卡
├── 批量导出
└── 历史记录管理
```
